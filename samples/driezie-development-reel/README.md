# Driezie Development Reel

来源：[Driezie Studio](https://driezie.studio/) 首页的 “In development” 横向项目带。

## 行为

- 保留原站七个在开发项目、高清原图、状态标签、左右按钮和上下文排版。
- 支持鼠标或触控按住拖拽，释放后根据距离与速度产生惯性切换。
- 支持焦点状态下使用键盘左右方向键切换。
- 三组项目卡片首尾衔接，过界后无动画复位，实现连续循环。
- 预览保留原页面相关说明和下方 Contact 引导，不包含顶部导航。
- 减少动态偏好下缩短过渡并关闭惯性。

## 参数

- 卡片宽度、间距、切换速度、拖拽惯性。
- 纸张、文字和强调色。
- 可关闭上下文，只保留项目带本体。

## 集成

组件画廊会生成独立运行 URL、参数化 URL、HTML Web Component、React iframe 示例和 JSON 参数文件。参数会写入 URL，因此可直接复制给其他产品加载。
