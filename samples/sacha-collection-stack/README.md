# Sacha Collection Stack

来源：[Sacha Haouzi](https://www.sachahaouzi.com/) 首页的 “Mapping organizations to design better websites” Collection 卡片。

## 行为

- 默认状态使用原站的 `10cqi / -5cqi / 5deg` 三层排布。
- 悬停和键盘聚焦切换为原站的 `20cqi / -10cqi / -4deg` 展开排布。
- 变换时长保持原站的 `0.9s`，并复刻其轻微过冲的 `linear()` 弹性曲线。
- 标题、分类标签、收藏图标和三张原始内容图一并保留；不包含原站顶部导航。
- 右侧控制器可以调整两种状态的展开距离、旋转、速度、圆角和颜色。

## 集成

组件画廊会为本组件生成独立运行 URL、参数化 URL、HTML iframe、React 封装代码和 JSON 参数文件。
