# Emotion Memory Landscape

提取自 [Emotion Agency](https://emotion-agency.com/) 首页首屏。组件保留首页主视觉的低多边形湖岸、中央粒子环、水面倒影、漂浮碎片和鼠标视差，并带入原页面的标题排版；入口页和顶部导航不在组件内。

## 使用

在 Sample 详情页调整参数后，可复制页面提供的 Runner URL 或 Embed 代码。参数会写入 URL，其他项目可直接加载同一效果。

## 交互

- 移动鼠标：镜头、粒子环和水面高光产生分层视差。
- 持续动画：粒子环旋转、碎片漂移、水面起伏。
- `prefers-reduced-motion`：自动降低运动幅度。
