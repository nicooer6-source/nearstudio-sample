# Wild Craft Pixel Field

直接抽取自 [Wild — Craft, Engineered](https://craft.wild.as/) 当前首页源码的像素交互首屏，源项目来自用户 GitHub 仓库 `nicooer6-source/craft-wild-as-mirror`。

组件保留原页面的标题、说明和首屏几何关系，去掉站点导航；运行时、Sneak 字体和 Wild 图形资源均托管在 Nearstudio。

## 原版交互

- 鼠标移动：按原算法连续盖章，快速移动也不会断线。
- 靠近标题：像素变成带流动高光的指向箭头。
- 停留：普通区域 1.5 秒、标题附近 2.4 秒后变为吃豆人并沿网格吃掉像素豆。
- 按住：2.2 秒达到满蓄力；松开后释放不受局部容器裁剪的高速冲击波。
- 双击：触发原版大范围爆发和画布震动。

## 参数

右侧面板覆盖源码中真实存在的像素尺寸、笔刷格数、时间倍率、轨迹衰减和五个色值。所有默认值均与原站源码一致，配置可以通过 URL 或嵌入代码复用。

缩略图使用真实首屏截图，避免画廊同时运行多份动画；详情和独立调用加载完整交互运行时。
